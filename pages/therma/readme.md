# THERMA 结构实验室

## 简介

可自由拆解和观察热泵洗烘一体机的三维结构实验室。通过整机、爆炸、剖视与热泵循环视图，探索机械层次、空气和冷媒回路的关系。

## 封面

![THERMA 结构实验室封面](./assets/cover.webp)

## 功能点

- 初始显示 65% 拆解的爆炸图，可切换整机、剖视图或热泵循环。
- 八类部件索引、模型拾取、标注、说明与单件观察。
- 拆解滑块、拆解动画、一键组装与独立暂停。
- 空气 / 冷媒流向、循环步骤和动态热泵回路。
- 相机旋转、缩放、透视 / 正视 / 侧视 / 俯视预设和自动旋转。
- 标注开关、沉浸展示，以及生成和下载高清 PNG。

## 技术栈

- 原生 HTML、CSS、JavaScript ES Modules；无框架、无后端。
- 本地 Three.js 0.185.0（WebGL 2）、OrbitControls、程序化机械几何与物理材质。
- GTAO、HDR 渲染目标、MSAA、接触阴影与本地摄影棚环境。

## 独立运行

完整复制本作品目录，保留所有子目录。在副本中运行以下命令即可单独预览。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

用支持 WebGL 2 的浏览器打开 <http://127.0.0.1:8000/>。目录可以改名，也可整体部署到静态站点的子路径。

## 操作说明

在合集仓库根目录运行 `pnpm dev`，打开 <http://localhost:5170/therma/>。

| 操作 | 效果 |
| --- | --- |
| 拖拽 / 滚轮 / 双指缩放 | 旋转和缩放模型 |
| 整机 / 爆炸图 / 剖视图 / 热泵循环 | 切换观察方式 |
| 点击部件、标注或结构索引 | 显示部件说明。点「单独查看此部件」可隔离观察，再点「返回整体结构」还原 |
| 拆解滑块 / 播放 / 一键组装 | 手调进度或播放拆装动画，组装后可再点「一键拆解」 |
| 热泵循环中的空气 / 冷媒回路 | 切换流向和四步说明，可独立暂停循环 |
| 画布获得焦点后 + / − / 0 | 缩放 / 重置相机 |
| 导出图片 | 按当前视角和画幅比例重新渲染，预览后下载 `THERMA-<视图模式>.png` |
| 沉浸 / Esc | 展开场景或退出沉浸 |

## 数据与限制

模型展示典型热泵洗烘结构，是为观察作出的简化，不对应在售机型，也不是维修拆机教程。界面“透视”表示斜向展示预设，底层使用正交相机。导出图包含模型、作品标识和视图名称，宽度最高 3840 px，高度和总像素受 4096 px、约 800 万像素的上限约束。视图和拆解进度仅在本次浏览中有效。
