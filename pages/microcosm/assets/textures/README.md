# 微境材质来源

照片扫描 PBR 贴图来自 Poly Haven，按 CC0 使用；贴图已下载到本目录，页面运行不连接外部 API。

- Rocky Terrain: https://polyhaven.com/a/rocky_terrain
- Bark Brown 02: https://polyhaven.com/a/bark_brown_02
- 许可说明: https://polyhaven.com/license

每组采用 1K JPEG 的 Diffuse、OpenGL Normal、ARM（R: AO / G: Roughness / B: Metallic）。下载后已核对服务端提供的 MD5。颜色贴图使用 sRGB，法线和 ARM 使用线性色彩空间。地形通过三向投影避免陡峭岩壁上的 UV 拉伸。
