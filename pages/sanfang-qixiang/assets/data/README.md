# 三坊七巷地图快照

- 数据文件：`map-data.json`。
- 来源：© OpenStreetMap contributors。
- 许可：[ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)。
- 获取日期：2026-10-23；坐标系统：WGS84。
- 内容：893 栋建筑轮廓、道路与水系、8 个精选景点、11 条坊巷及资料来源链接。

原始坐标保留在 JSON 中，运行时投影为街区局部米制坐标。建筑高度、屋顶、门窗、绿化、街灯、游客和天气均为示意。

页面保留地图归属、许可与资料链接；独立复用数据时需继续保留归属，并遵循 ODbL 对衍生数据库的要求。

## 爱心榕树

`landmarks.js` 独立维护爱心榕树信息，不改写原始 OSM JSON，也不将其关联到其他建筑。

- 形态参考：[福建省政府的爱心树实景报道](https://www.fujian.gov.cn/english/news/202109/t20210910_5684845.htm)。
- 位置依据：[央广网关于南后街安民巷附近爱心树的现场报道](https://m.fznews.com.cn/dsxw/20210908/6138277c6c90a.shtml)。
- 树形、约 25 米冠幅与约 30 米高度依据照片比例作风格化建模；落点依据快照中的南后街、安民巷路网示意选取，非实测树木坐标。
- 实景照片仅供观察，不作为项目贴图或静态资源分发；树皮、树冠与叶片均由程序生成。

## 林则徐纪念馆

`linzexu-memorial.js` 独立保存馆区边界和补建布局，`guide-model.js` 生成派生数据，原始 `map-data.json` 保持不变。

- 馆区边界：[OSM way/705649920](https://www.openstreetmap.org/way/705649920)，版本 4，2026-10-27 读取，WGS84 / ODbL 1.0。该要素是 `tourism=museum` 用地，不能当成整栋建筑挤出。
- 内部布局：[现场导览图](https://commons.wikimedia.org/w/index.php?curid=80487736)，董辰兴摄于 2019-07-18，CC BY-SA 4.0。补建布局依同一许可提供，照片只供观察，不作为项目贴图或静态资源分发。
- 补建 21 块独立建筑，覆盖 A—E 展厅、树德堂、海纳厅、左海厅、有容斋、云左阁、御碑亭等；保留庭院、水池和入口通道。内部轮廓、落点、高度及细部是导览图参考下的示意，不代表测绘成果或现状调查。
- 本地建筑使用负数 ID 和显式 `siteId` 关联，不伪造 OSM 建筑 ID，也不将邻近的三坊七巷游客中心改为纪念馆。统一模型供建筑渲染、列表选择、小地图、拾取和相机取景消费。
- 东南角现有建筑 [OSM way/705649921](https://www.openstreetmap.org/way/705649921) 保留“三坊七巷游客中心”名称；现场导览图将其单列为 23 号。地图提供可选名称标签，不把配套服务建筑计入精选或纪念馆展厅高亮。
