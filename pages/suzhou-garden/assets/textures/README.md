# 材质来源

扫描贴图及 HDR 天空来自 [Poly Haven](https://polyhaven.com/)，以 [CC0](https://polyhaven.com/license) 使用。

- [Stone Floor](https://polyhaven.com/a/stone_floor)：青石路面。
- [Rock Pitted Mossy](https://polyhaven.com/a/rock_pitted_mossy)：叠石、岸石；着色器降低原扫描色彩饱和度。
- [White Plaster 02](https://polyhaven.com/a/white_plaster_02)：粉墙。
- [Aerial Grass Rock](https://polyhaven.com/a/aerial_grass_rock)：地表。
- [Bark Brown 02](https://polyhaven.com/a/bark_brown_02)：树皮，复制本仓库已有 1K 资源。
- [Kloofendal 48d Partly Cloudy Pure Sky](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky)：2K 白昼 HDR 天空。
- [Qwantani Sunset Pure Sky](https://polyhaven.com/a/qwantani_sunset_puresky)：1K 夕照 HDR 天空。

新下载资源均与 API 提供的 MD5 校验一致。扫描贴图使用 1K JPEG，Diffuse 为 sRGB，OpenGL 法线和 ARM 为线性数据。ARM 的 G 通道作为粗糙度；此页面没有将岩石误标为金属。下载清单位于 `sources.json` 和 `sky-sources.json`。

其余木纹、筒瓦、叶簇、荷叶纹理和匾额由本页面原创 Canvas 程序生成。无运行时外链资源。
