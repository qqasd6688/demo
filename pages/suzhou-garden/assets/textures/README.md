# 听雨园材质来源

园中五组扫描贴图和两幅 HDR 天空来自 Poly Haven，按 CC0 使用。文件都随作品发布。[Poly Haven 许可](https://polyhaven.com/license)

| 素材 | 在园中的用途 |
| --- | --- |
| [Stone Floor](https://polyhaven.com/a/stone_floor) | 青石路面 |
| [Rock Pitted Mossy](https://polyhaven.com/a/rock_pitted_mossy) | 叠石、岸石 |
| [White Plaster 02](https://polyhaven.com/a/white_plaster_02) | 粉墙 |
| [Aerial Grass Rock](https://polyhaven.com/a/aerial_grass_rock) | 地表 |
| [Bark Brown 02](https://polyhaven.com/a/bark_brown_02) | 树皮，三张贴图保存在本目录 |
| [Kloofendal 48d Partly Cloudy Pure Sky](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky) | 2K 白昼天空 |
| [Qwantani Sunset Pure Sky](https://polyhaven.com/a/qwantani_sunset_puresky) | 1K 夕照天空 |

每组扫描材质含三张 1K JPEG，共 15 张。Diffuse 使用 sRGB，OpenGL 法线和 ARM 使用线性数据，粗糙度取 ARM 的绿色通道。木纹、筒瓦、叶簇、荷叶与匾额由 Canvas 绘制。[材质实现](../materials.js)

贴图清单记录了路面、叠石、粉墙和地表四组的下载地址、大小和 MD5。树皮沿用仓库已有素材，来源见上表的 Bark Brown 02。两幅 HDR 的下载地址和 MD5 单列在天空清单中。[贴图清单](./sources.json) · [天空清单](./sky-sources.json)
