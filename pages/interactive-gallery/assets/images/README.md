# 数字展厅素材

- `starfield.webp`：为展厅生成的星空背景，保留 1774×887 原尺寸。展厅预加载该图片，星点闪烁、流星和上升光线由场景单独绘制。
- `world-land.json`：Natural Earth 1:110m 陆地轮廓，本地快照来自 [natural-earth-vector / ne_110m_land.geojson](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson)。Natural Earth 数据为公有领域；仅用作装饰球面的点阵轮廓，不提供行政区划或精确地图功能。

运行时不请求外部图片或地图服务。
